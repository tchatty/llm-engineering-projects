# LLM Engineering Projects

A collection of personal projects created while completing Ed Donner's LLM Engineering course.

This repository contains projects that began as learning exercises and evolved into standalone applications and experiments in:

- Retrieval-Augmented Generation (RAG)
- Prompt Engineering
- LLM Application Architecture
- Gradio Interfaces
- Agent Workflows
- Document Processing
- Sustainability & AI Research

---

## Projects

### Sustainability of AI RAG Assistant

A Retrieval-Augmented Generation research assistant focused on the environmental impacts of artificial intelligence.

Features:

- Research paper knowledge base
- Semantic search using embeddings
- Citation-enabled answers
- Grounded responses
- Gradio interface
- Expandable sustainability corpus

Status:

✅ V1 Complete

Planned:

- Improved citation tracking
- ChromaDB integration
- Evaluation framework
- Research paper comparison workflows
- Public deployment

---

### Dynamic Web PDF Summarizer

Summarizes PDFs retrieved from web sources using frontier language models.

Focus Areas:

- Document ingestion
- Summarization
- Prompt engineering

---

### Open Source Web Scraper

Experiment exploring structured extraction of content from publicly available websites.

Focus Areas:

- Data ingestion
- Parsing
- Automation workflows

---

### Technical Concept Explainer

An LLM-powered utility that explains technical topics at multiple levels of complexity.

Focus Areas:

- Prompt engineering
- Explanatory AI
- User experience

---

### Three-Way LLM Chat

A comparison interface allowing multiple language models to respond to the same user prompt.

Focus Areas:

- Model comparison
- Prompt testing
- LLM evaluation

The goal of this repository is to learn AI engineering by building practical applications rather than isolated tutorials.

Projects are intentionally iterative and may evolve from notebooks into fully developed applications over time.
